# Tools

Offline analysis helpers. They do **not** change mainnet consensus parameters.

| Script | Purpose |
|--------|---------|
| `simulate_difficulty.py` | Difficulty parameter sweep (research) |
| `stochastic_validate_w30.py` | Stochastic checks for the W30 / 1/16 retarget |

Run from repo root with `PYTHONPATH=.`.
